# Artsy Public API

> Artsy's Public API (v2) is a HAL hypermedia REST API exposing Artsy's database of artists,
> artworks, genes (Art Genome Project categories), shows, partners, fairs, and auction sales.
> Authentication uses an application-level X-Xapp-Token minted from a client_id/client_secret.
> Note: Artsy has announced the public API is being retired and may be taken down without notice.

## APIs
- [Artsy Public API v2](https://api.artsy.net/api): HAL root listing every resource link.
- [Developer Documentation](https://developers.artsy.net/): Public API v2 docs.
- [Authentication](https://developers.artsy.net/v2/docs/authentication): XApp token flow.
- [Metaphysics GraphQL API](https://github.com/artsy/metaphysics): Artsy's GraphQL API (separate surface).
